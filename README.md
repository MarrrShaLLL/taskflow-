# Taskflow

Taskflow-ը առաջադրանքների կառավարման հրամանային տողային ծրագիր է։ Այն թույլ է
տալիս ավելացնել առաջադրանքներ, նշել դրանք որպես ավարտված և տեսնել բաց ու
ավարտված առաջադրանքների քանակը։

## Պահանջներ

- Python 3
- Windows PowerShell

## Տեղադրում

Բացեք PowerShell-ը նախագծի պանակում և ստեղծեք վիրտուալ միջավայր.

```powershell
python -m venv .venv
```

Ակտիվացրեք վիրտուալ միջավայրը.

```powershell
.\.venv\Scripts\Activate.ps1
```

Տեղադրեք անհրաժեշտ գրադարանը՝ `requirements.txt` ֆայլից.

```powershell
python -m pip install -r requirements.txt
```

## Գործարկում

Նախագծի հիմնական պանակից գործարկեք.

```powershell
python -m taskflow
```

Ծրագիրը բացում է ընտրացանկ՝ առաջադրանքները ցուցադրելու, ավելացնելու կամ
ավարտելու համար։ Առաջադրանքները պահպանվում են նախագծի հիմնական պանակի
`tasks.json` ֆայլում։

## Կախվածություններ

Արտաքին կախվածությունների ցանկն ու տարբերակները նշված են
 ֆայլում։
